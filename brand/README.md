# Veritane brand assets

- `mark.svg` — primary mark. The lens uses `currentColor`; the clarified line is lens teal `#0B7A75` (use `#5EEAD4` on dark backgrounds, or `var(--accent)` when inlined).
- `mark-mono.svg` — single colour (`currentColor`).
- `icon-512.svg` — app icon (Windows/Android), teal rounded square with a white mark. Source for `tauri icon`.
- `icon-maskable.svg` — full-bleed variant for the web manifest / Android adaptive icon (mark inside the central 80 %).
- Wordmark: lowercase `veritane` in Source Sans 3, `veri` weight 400 + `tane` weight 700, tracking −0.01em, colour `--text`, mark on the left.

Idea: Latin *veritas* (truth) — a clear, honest lens on money. A noisy line goes into the lens and comes out straight.
Rules: minimum size 16 px (drop the end dot below 24 px); clear space = half the lens diameter on all sides; no gradients, no shadows, no recolouring outside the tokens.
